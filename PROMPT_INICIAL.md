# Prompt inicial para Codex
Você é responsável pela implementação do Redação Lab, aplicativo Android pessoal offline-first para preparação ao vestibular da Unisinos. O diretório atual contém a especificação aprovada. Leia integralmente AGENTS.md, README.md, PRD.md, ARCHITECTURE.md, DATABASE.md, SECURITY.md, CONTENT.md, AI_INTEGRATION.md e BACKLOG.md. Não faça uma nova etapa extensa de planejamento.

Execute a primeira fatia vertical B01–B04, começando por verificar o ambiente Windows, Node/npm, JDK, Android SDK, Gradle wrapper quando criado e Git. Informe bloqueios reais e solicite apenas intervenções indispensáveis. Se o ambiente permitir, implemente de fato; não entregue somente sugestões. Use Vue 3/TypeScript/Vite/Capacitor, SQLite privado, migrations e seed original. Crie navegação, configuração inicial simples, leitor, progresso, anotações vinculadas aos trechos e marcações para reforço. Conteúdo inicial próprio conforme CONTENT.md. Não copie o APK de referência nem use conteúdo não autorizado.

Entregue primeiro uma versão debug instalável com estudo offline. Execute typecheck, testes, build web, cap sync e build Android. Se houver telefone autorizado, valide instalação, persistência após reinício e modo avião; não assumir que há dispositivo conectado. Não sobrescreva app existente nem apague dados. Registre caminho absoluto do APK real, comandos de instalação e resultados. Atualize BACKLOG e README com status comprovado e pendências. Prepare próximas etapas B05+ sem implementá-las antes do gate G1, salvo dependência necessária.

Restrições: nenhum backend/login, nenhuma API paga, nenhum token de sessão do ChatGPT, nenhuma telemetria. Não adicionar funcionalidades não essenciais. Não comprometer migrations ou integridade para ganhar tempo. Se SDK faltar, fornecer instalação oficial e continuar apenas no que for verificável. Ao concluir, apresentar resumo técnico, arquivos alterados, testes executados, falhas, localização do APK e próximo prompt recomendado.
